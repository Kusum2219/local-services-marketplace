# Local Services Marketplace

A full-stack marketplace for discovering, comparing, and booking verified local service providers.

## Status

🚧 Under Development

## Planned Stack

- React
- TypeScript
- Node.js
- Express
- PostgreSQL
- Prisma
- JWT Authentication

## Features

- Customer authentication
- Vendor onboarding 
- Service listings
- Availability slots
- Booking
- Double-booking prevention
- Reviews
- Admin moderation
